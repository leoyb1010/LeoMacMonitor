# LeoMac监控器 1.0.0

首个公开版本，面向 Apple Silicon Mac 和小尺寸副屏。

## 主要功能

- CPU、GPU、内存、内存带宽八模块实时仪表盘
- AI 工作负载、神经网络引擎、媒体引擎状态
- CPU、GPU、内存温度和风扇转速
- 网络、磁盘实时吞吐与历史曲线
- 90%–250% 界面缩放和紧凑副屏布局
- 菜单栏监控面板与 WidgetKit 桌面组件
- 跟随系统的深色、浅色外观

## 安装说明

下载 DMG 后，将 LeoMac监控器拖入“应用程序”。当前构建使用 Apple Development 证书签名，
尚未完成 Developer ID 公证；如果 macOS 首次阻止打开，请在 Finder 中右键应用并选择“打开”。
