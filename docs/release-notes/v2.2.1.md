# LeoMac监控器 2.2.1

## Agent 运行状态补全

第三行原来的“AI 运行时”只负责 Ollama、MLX、LM Studio 等本地模型服务，因此即使上方已经识别 Codex、Claude 与 WorkBuddy，这里仍会显示“未检测到运行时”。2.2.1 将该区域改为“Agent 运行状态”，优先展示 Coding Agent 明细。

- Codex、Claude、WorkBuddy 固定显示，其他已识别 Agent 自动追加。
- 每行显示工作中、刚活跃、等待或未运行，以及进程数、CPU 和内存。
- 点击正在运行的 Agent 可以打开对应主进程检查器。
- Ollama、MLX、LM Studio 等继续保留在下方“本地模型”区域，两类运行时不再混淆。
