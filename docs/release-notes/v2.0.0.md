# LeoMac监控器 2.0.0

## 八张卡，两种观察方式

- 数据面继续提供适合小副屏的高密度实时读数、进度条和历史曲线。
- 动效面以整张卡为画布，用大型实时图形表达同一组监控数据。
- 每张卡右下角可独立翻转，也可以在标题栏切换“数据 / 动效 / 混合”全局模式。
- 两个面共用完全相同的卡片边界，翻转时 4×2 网格不会伸缩、换行或错位。

## 八种数据驱动视觉

- CPU：P/E 核心反应堆，负载、频率与受限状态共同改变转速和亮度。
- GPU：粒子星云和显存环，计算负载与显存占用决定粒子密度和轨道。
- 内存：分层液位，固定、活跃、压缩和可用内存组成实时水位。
- 带宽：CPU、GPU、媒体引擎及其他流量的四条并行数据通道。
- AI 工作负载：CPU、GPU、ANE、媒体引擎星图，活跃路径随负载流动。
- 传感器：温度等高线与真实 RPM 风扇，无风扇设备不会伪造转动。
- 网络：下载与上传两股相反方向的波形及数据包。
- 磁盘：读取与写入双向 I/O 涡轮，外围容量环表达已用空间。

## 动效与性能

- 使用原生 SwiftUI Canvas 和可中断的 3D 翻转，不引入额外运行时依赖。
- 仅可见的动效面刷新；隐藏面、非活跃窗口和“减少动态效果”模式自动暂停。
- 状态栏继续使用独立 100% 字体尺度，不跟随主控 200%–250% 缩放。
