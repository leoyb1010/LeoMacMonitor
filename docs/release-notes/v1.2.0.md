# LeoMac监控器 1.2.0

## 磁盘智能监控

- 显示当前读写最活跃的进程，并用五秒平滑避免瞬时抖动
- 分别显示内置 SSD 与外置物理磁盘吞吐，自动排除虚拟磁盘映像
- 后台低频读取 SMART/NVMe 温度、寿命消耗、累计读写、异常关机及介质错误
- 点击首页磁盘卡片的“最忙进程”即可打开完整详情

## 菜单栏升级

- 菜单栏字体与主仪表盘缩放完全分离并整体放大
- 综合面板加宽、加长，加入可展开的进程活动和物理磁盘健康详情
- 单项面板统一改为 420pt 宽的可滚动长面板，不再因为内容多而被截断

## 小屏动态图形

- 八个监控模块仍使用八种不同的 Orbs 造型，不做同形复制
- 增强点阵尺寸、明暗对比、辉光与空闲态运动，在小副屏上也能一眼辨认
- 200% 以上缩放设有尺寸上限，不挤压标题、数值和菜单栏固定布局

## 兼容性

- 旧版会话记录仍可正常读取；新增磁盘字段在旧记录中按“不可用”处理
- 不申请管理员权限，不引入特权 Helper，不启用自动更新
