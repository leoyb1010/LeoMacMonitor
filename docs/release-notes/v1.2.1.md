# LeoMac监控器 1.2.1

## 八卡布局校准

- CPU、GPU、内存、带宽、AI 工作负载、传感器、网络与磁盘统一放入共享 4×2 网格
- 第一行和第二行严格使用相同的四列宽度、242pt 行高与统一间距
- 两行共同占用区域较 1.2.0 增高约 10%，实时曲线获得更多纵向空间
- 在 1280×720 副屏、200% 界面缩放下仍能完整显示四列，不产生横向滚动
- 下方 AI 运行时、进程标题和固定记录栏继续保留在首屏可见范围内

## 兼容性

- 不改变监控采样、菜单栏、Widget、缩放设置与磁盘智能监控数据结构
- 可直接覆盖安装 1.2.0，用户设置和历史记录保持不变
