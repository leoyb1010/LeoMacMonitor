# LeoMac监控器 2.2.0

## Coding Agent 实时监控

“AI 工作负载”现在直接观察这台 Mac 上运行的 Coding Agent。Codex、Claude 和 WorkBuddy 固定在首屏，其余已识别的 OpenCode、Gemini、Cursor Agent 与 Copilot 会自动补充显示。每个 Agent 按整个进程家族汇总 CPU、内存、磁盘读写和进程数，点击该行可以进入现有的进程检查器。

状态严格来自本机可验证的资源信号：“工作中”表示当前有明显 CPU 或磁盘活动，“刚活跃”保留短暂活动余辉，“等待”表示进程仍在但资源活动很低，“未运行”表示没有发现对应进程。应用不会读取提示词、对话、源码内容或文件名，也不会把资源活跃度冒充成具体任务阶段。

菜单栏监控中心的加速器摘要也同步改为当前主 Agent 与状态，并继续使用独立的正常显示器字号，不受主控页面 200% 缩放影响。

## Agent 雷达动效

AI 卡片背面改为 Agent 雷达星图。Codex、Claude、WorkBuddy 是固定锚点，其他已发现的 Agent 自动加入星图；工作中的节点会连续扩散雷达环，连接线与往返数据包随实时负载改变，等待与离线节点保持低亮度呼吸。所有脉冲采用错相淡出与连续时间基准，不会在循环边界卡一下再重播。

## 小副屏排版

面向 1280×720 小副屏和 200% 字体缩放，Agent 状态总览与三条主 Agent 数据行采用更紧凑的固定列宽，内存根据数值自动显示为 MB 或 GB。模块仍保持两行四列、统一宽高与间距，不会因为 Agent 名称或资源数字改变而换行或撑乱网格。
