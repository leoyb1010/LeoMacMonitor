# LeoMac监控器 2.1.0

## 巨型模块水印

八张动效卡都增加了与模块对应的端正超大名称水印。水印位于动态图形背后，使用模块强调色进行约 6.8 秒一次的慢速呼吸显隐：最淡时只留下背景轮廓，显现时足以在小副屏上一眼识别 CPU、GPU、内存、带宽、AI、传感器、网络和磁盘，同时不会抢走实时图形与底部关键读数的层级。

## 真正无缝的无限动效

- 旋转、轨道和波形不再使用“绝对时间 × 实时负载”的相位公式，监控数据每秒更新时不会瞬移。
- CPU、GPU 和磁盘使用恒定连续相位，负载负责弧长、密度、亮度和振幅。
- AI 脉冲与网络数据点使用平滑往返曲线，在端点自然减速和反向。
- 带宽数据包在卡片边界淡出与淡入，消除从右端跳回左端的剪切感。
- 内存液位、温度等高线和风扇均采用连续周期，隐藏卡面、失焦和“减少动态效果”仍会自动暂停。

## 更高的八卡舞台

第一、第二行核心卡共用的固定行高由 242pt 提升到 258pt，八张卡仍严格使用相同的四列宽度、上下行距与高度。增加的空间由大型动态图形吸收，第三行 AI 运行时和进程区域整体下移，1280×720 小副屏仍保留底部记录栏。
